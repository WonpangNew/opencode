Use this tool to read your current subagent plan for the session. Returns the list of planned subagent tasks with their status, subagent_type, and prompts.

Use proactively:
- At the start of a conversation to see pending subagent work
- Before starting new Tasks to prioritize and avoid duplication
- When user asks about previous plans or progress
- After completing a Task to see what's next
- Whenever uncertain about remaining subagent work

Usage: Leave the input blank. Returns items with id, content, status, priority, subagent_type, and prompt. If no items exist, returns an empty list.
