Use this tool to create and manage a structured subagent plan for your current session. Each item represents a subagent task to be executed via the Task tool.

This helps you plan which specialized subagents to launch, in what order, and with what prompts. After creating the plan, use the Task tool to execute each item (launch the subagent with the specified subagent_type and prompt), then update the plan status via this tool.

## When to Use This Tool
Use proactively when:
1. Complex multistep tasks require 3+ distinct subagent invocations
2. Multiple specialized agents should run (e.g. explore + generalPurpose + code-reviewer)
3. User provides multiple tasks that map to different agent types
4. After receiving new instructions - capture subagent work as plan items
5. After a Task completes - mark that item completed and update in_progress for the next

## When NOT to Use
Skip when:
1. Single straightforward task - call Task directly
2. Trivial work that needs no orchestration
3. Task can be done in 2 steps - just call Task twice
4. Purely conversational/informational - no subagents needed

## Task States
- pending: Not yet started
- in_progress: Currently being executed (only ONE at a time)
- completed: Subagent finished successfully
- cancelled: No longer needed

## Task Management
- Update status in real-time as Tasks complete
- Mark completed IMMEDIATELY after each Task finishes
- Only ONE in_progress at any time
- Use Task tool to execute each item; use this tool to plan and track
- Each item should include subagent_type (e.g. explore, generalPurpose) and prompt (detailed instructions for that agent) so the Task tool can execute it

## Task Breakdown
- Create specific, actionable subagent items
- Each item = one Task call with subagent_type + prompt
- Use clear prompts so the subagent knows exactly what to do and what to return
